# 📈 NVIDIA Stock Market Analysis & Forecasting

An end-to-end financial analytics project that combines technical analysis, machine learning, deep learning, and sentiment analysis to study and forecast NVIDIA stock trends.

---

## 🚀 Project Overview

This project explores NVIDIA stock data from 1999–2026 and builds a complete analytics pipeline for investors and financial analysis.

The project focuses on:

- Historical trend analysis
- Technical indicators
- Volatility and returns analysis
- Machine learning models
- LSTM deep learning prediction
- Sentiment analysis using financial news and Reddit discussions

**Goal:** Provide data-driven insights rather than attempting perfect stock prediction.
